Relay stays beside SAP in Chrome and turns reviewed descriptions into approval-gated DEV changes.

01

Add Relay to Chrome

Extract the extension ZIP. Open chrome://extensions, enable Developer mode, choose Load unpacked, and select the folder containing manifest.json.

Pin Relay and click its icon. You can also use ⌘ ⇧ Y on Mac or Ctrl Shift Y on Windows and Linux.

02

Connect your workspace

Start the backend, open Connection settings, enter http://127.0.0.1:8000, and use the Relay access token from the private backend configuration.

SAP service keys and AI provider keys stay in the backend. Never paste them into the side panel.

03

Describe. Review. Approve.

Choose a package and describe the input, rules and expected output. Relay derives a typed pipeline for validation, mapping, calculations, filtering, deduplication, sorting, routing and response shaping.

Inspect what Relay understood and the before/after plan. The iFlow is uploaded only after an approver selects Create iFlow & deploy.

04

Configure real connections

Scenarios requiring SFTP, SOAP, OData, AS2, mail, JMS, AMQP, databases or ERP writes need an adapter module and connection details. Relay asks for these instead of pretending that a local response performed the external operation.

Permissions & distribution

This developer build requests side-panel access, session storage and the two localhost backend origins. It does not read SAP browser sessions or inject page scripts.

Public distribution needs a hosted authenticated backend, privacy disclosures, store assets and Chrome Web Store review.
